# Flowing Light – Animated Backgrounds

Two seamless animated backgrounds for apps, games, menus and streams, in 4K and for phones.

| | Cosmic Violet (dark) | Marble Gold (light) |
|---|---|---|
| Live loop 4K (3840×2160) | `Cosmic_Violet_Live_4K.mp4` | `Marble_Gold_Live_4K.mp4` |
| Live loop phone (2160×3840) | `Cosmic_Violet_Live_Phone.mp4` | `Marble_Gold_Live_Phone.mp4` |
| Still 4K | `Cosmic_Violet_4K.png` / `.jpg` | `Marble_Gold_4K.png` / `.jpg` |
| Still phone (2160×3840) | `Cosmic_Violet_Phone.png` / `.jpg` | `Marble_Gold_Phone.png` / `.jpg` |

The phone versions are composed for a tall screen (not cropped from the landscape ones): the same look, the
same effects, laid out for portrait.

**Cosmic Violet:** violet silk ribbons in deep space. Light pulses run along the ribbons, waves of light flow
through the silk, stars twinkle, shooting stars cross the sky.

**Marble Gold:** cream marble with sweeping layers and fine gold lines. Golden light runs along the lines, a sheen
glides over the stone, dust floats in the light.

All loops: H.264, BT.709, 25 fps, 20 seconds, seamless (the last frame flows into the first). For a background
in HTML: `<video autoplay muted loop playsinline src="Cosmic_Violet_Live_4K.mp4"></video>`.
